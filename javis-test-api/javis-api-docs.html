API Docs

Tài liệu hướng dẫn sử dụng toàn bộ các endpoint của Javis Chatbot API — từ chat, ingest transcript meeting đến upload tài liệu công ty.

Base URL
http://localhost:8019/api/v1
Swagger Docs
GET /docs
💡 Nếu server chạy với APP_PORT=8000, đổi port thành 8000. Base URL trong Postman collection dùng biến {{chatbot_url}}.
POST

Chat

/api/v1/chat

Gửi tin nhắn đến chatbot. Hỗ trợ 3 chế độ: hỏi dữ liệu meeting transcript, hỏi tài liệu công ty, hoặc web search.

Request Body

FieldTypeBắt buộcMô tả
messagestring✓ Câu hỏi gửi đến chatbot
modestring✓ customer_data — hỏi dữ liệu transcript
company_info — hỏi tài liệu công ty đã upload
web_search — tìm kiếm web (stub)
rolestring✓ user — chỉ truy cập dữ liệu của chính mình
admin — truy cập across users hoặc theo target_user_id
user_idUUID✓ ID của người dùng đang gửi tin
target_user_idUUIDoptional Dùng khi role=admin, query dữ liệu của user khác
conversation_idUUIDoptional ID cuộc hội thoại để giữ context nhiều lượt
JSON Body 
{
  "message": "5月26日の会議で、第2四半期の予算はいくらでしたか？",
  "mode": "customer_data",
  "role": "user",
  "user_id": "00000000-0000-0000-0000-000000000001",
  "target_user_id": null,
  "conversation_id": null
}
cURL 
curl -X POST http://localhost:8019/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "今月の会議の概要を教えてください",
    "mode": "customer_data",
    "role": "user",
    "user_id": "00000000-0000-0000-0000-000000000001"
  }'
POST

Ingest Transcript

/api/v1/chat/transcript/ingest

Upload và xử lý transcript meeting. API trả về ngay lập tức, việc ingest chạy background. Dùng GET transcript status để kiểm tra tiến trình.

POST ingest
→
nhận transcript_id
→
polling status
→
ready ✓

Request Body

FieldTypeBắt buộcMô tả
user_idUUID✓ID người dùng sở hữu transcript
transcriptstring✓Nội dung transcript, format [HH:MM:SS-HH:MM:SS][Tên] nội dung
meeting_datestringoptionalNgày họp, format YYYY-MM-DD
session_idstringoptionalID phiên họp để deduplicate
participantsarrayoptionalDanh sách tên người tham gia
speaker_countintoptionalSố người nói
force_reingestbooleanoptional false (default) — bỏ qua nếu đã tồn tại
true — xóa và ingest lại
JSON Body 
{
  "session_id": "meeting-001",
  "user_id": "00000000-0000-0000-0000-000000000001",
  "meeting_date": "2026-05-27",
  "participants": ["田中", "佐藤"],
  "speaker_count": 2,
  "force_reingest": false,
  "transcript": "[00:00:00-00:00:05][話者1] お疲れ様です。"
}

Response

200 OK 
{
  "status": "success",
  "data": {
    "transcript_id": "e0b87850-6ea0-58f5-9bfc-afa606d33754",
    "status": "ingesting",
    "chunk_counts": {},
    "error": null
  }
}
cURL 
curl -X POST http://localhost:8019/api/v1/chat/transcript/ingest \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "00000000-0000-0000-0000-000000000001",
    "meeting_date": "2026-05-27",
    "force_reingest": false,
    "transcript": "[00:00:00-00:00:05][話者1] お疲れ様です。"
  }'

Path ParamTypeMô tả

200 OK — ready

  "data": {

Upload Company Document

/api/v1/chat/company/upload

Upload tài liệu công ty (PDF, DOCX, TXT, MD) để chatbot có thể trả lời câu hỏi ở mode company_info. Xử lý chạy background, trả về ngay.

⚠️ Request type phải là multipart/form-data. Không set header Content-Type thủ công — để Postman hoặc client tự thêm boundary.

Form Fields

FieldTypeBắt buộcMô tả
fileFile✓ File cần upload. Định dạng hỗ trợ:
.pdf .docx .txt .md
force_reingeststringoptional "false" hoặc "true" (string, không phải boolean)
200 OK 
{
  "status": "success",
  "data": {
    "upload_document_id": "...",
    "filename": "company_doc.md",
    "content_type": "text/markdown",
    "size_bytes": 1234,
    "document_id": "b45ba2f5-ed0b-5d42-bee1-247e53cd2f62",
    "status": "ingesting",
    "chunk_count": 0,
    "error": null
  }
}
cURL 
curl -X POST http://localhost:8019/api/v1/chat/company/upload \
  -F "file=@/path/to/document.md" \
  -F "force_reingest=false"
💡 Dùng document_id (không phải upload_document_id) để check status.
GET

Trạng thái Ingest

Cả transcript lẫn document đều có lifecycle như sau:

ingesting
Đã nhận request, đang xử lý ban đầu
enriching
Đang enrich metadata bằng LLM
embedding
Đã ghi DB, đang sync Qdrant
ready
Hoàn tất, có thể query được
failed
Ingest thất bại, xem field error

📮 Postman Tips

Hướng dẫn nhanh dùng Postman collection.

🔧 Set biến chatbot_url = http://localhost:8019 trong Postman Environment.
RequestCách config trong Postman
Chat / Ingest Transcript Body → raw → chọn JSON
Upload Document Body → form-data → key file chọn type File, chọn file; key force_reingest type Text
Content-Type với upload Không set thủ công — Postman tự gán multipart/form-data; boundary=...
