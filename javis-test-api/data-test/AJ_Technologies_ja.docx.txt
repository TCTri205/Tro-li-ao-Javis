AJ Technologies – 会社概要 
株式会社AJテクノロジーズ (AJ Technologies Co., Ltd.) は、日本を拠点とするテクノロジー企業であり、デジタルプラットフォームの開発や先端技術を活用したソリューション提供を専門としています 。特に金融および不動産・住宅分野に強みを持っています 
1. 基本情報
* 会社名: 株式会社AJテクノロジーズ (AJ Technologies Co., Ltd.) 
* 本社所在地: 愛知県名古屋市中区栄2-2-23 アーク白川公園ビルディング7F 
* 代表取締役: 山下善央 (Yoshio Yamashita) 
* 設立: 2022年10月 
2. 主な事業領域 AJ Technologies は、AI技術を活用したデジタルプラットフォーム企業として、日本の金融および不動産・住宅業界に革命を起こすことに注力しています 。
* 住宅ローンプラットフォーム事業: 住宅ローン借入プロセスに関連するテクノロジーソリューションの統合サービス 。
* AIソリューション事業: 業務プロセスの自動化と最適化を支援するAIサービスの開発 。
* 工務店向け営業DX: 工務店や建設会社の営業プロセスのデジタル化および改善支援 。
* OCRサービス「ラクかりex（AI-OCR）」: AIを搭載した光学文字認識ソリューション。特に金融やローン関連書類の自動読み取り・処理に特化 。
3. 企業関係 
* VJ Technologies: AJ Technologies のベトナム子会社。高度なスキルを持つエンジニアチームであり、日本側と共同でソフトウェア開発のニーズに対応 。
* ONE Financial Service: 住宅ローンの選択および手続き支援において、日本法に基づいた「金融サービス仲介業者」として登録・参画 。
4. 注目の製品・機能（DXプラットフォーム「ホムすん」） 「ホムすん」は、住宅建設・住宅ローン・顧客コミュニケーションに関連する業務を最適化する工務店向けDXプラットフォームです 。
* AIによる銀行書類自動作成: 書類を撮影するだけで、ローン申請に必要なPDFファイルを自動生成 。
* AIチャットボット: 自然言語処理（NLP）を用いて、FAQ対応、予約受付、24時間365日の営業支援を実現 。
* 音声認識＆議事録作成: 音声を構造化されたテキストに自動変換 。
* 施工進捗管理: AIが工事の進捗を測定・記録し、プロジェクト管理を支援 。
* 書類管理: OCRとAIにより書類を電子化し、重要情報を自動抽出 。
* 住宅ローン分析・提案: 履歴データとアルゴリズムに基づき、借入可能額の予備評価を実施
